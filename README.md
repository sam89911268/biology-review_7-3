# 七下第三次段考生物複習

這是一個純 HTML/JavaScript 的選擇題練習頁面，可直接放到 GitHub Pages 測試。

## 檔案說明

- `index.html`：主要練習頁面。
- `biology-plant-questions.js`：植物界題庫。
- `biology-animal-questions.js`：動物界題庫。
- `biology-ecosystem-questions.js`：生態系題庫。
- `biology-human-environment-questions.js`：人類與環境題庫。
- `biology-review-questions.js`：總題庫入口，負責彙整各範圍題庫。

## 之後新增題庫

新增或替換題庫時，建議每個範圍維持獨立題庫檔。新增後，記得在 `index.html` 中先載入新題庫檔，再由 `biology-review-questions.js` 彙整。
